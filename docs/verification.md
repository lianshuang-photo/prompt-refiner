# 验证范围

当前发行版本为 0.3.4，属于开发预览版，功能和兼容性仍在迭代。

## 0.3.4 发布检查

- 39 项自动检查通过，完整构建与原生图标打包成功。
- 安装包为 Apple Silicon arm64，最低部署版本 macOS 14。解压后应用版本正确，签名完整性验证通过，二进制与打包前一致；运行依赖均为系统库，MIT 许可证包含在 App 内。
- 从解压目录启动命令行改写检查，使用 Codex CLI 0.164.0-alpha.11.1 成功完成 3 次只读工程查询并返回结构化改写；合成测试工程内容保持不变。
- 原生设置界面预览使用隔离的演示配置导出，没有启动生成或写入登录项。
- 发布资产附带 SHA-256 校验文件。当前使用 ad-hoc 签名，未做 Apple 公证；解压运行检查不等同于新电脑的 Gatekeeper 或全系统版本验收。

- 39 项自动检查，覆盖文本与 Unicode 选区保护、撤销范围、原会话唯一匹配、数据库只读访问、Codex 超时与取消、事件解析及工程权限配置。
- Release 构建、图标打包、应用包签名完整性及安装资源一致性。
- 原生界面中切换 Augment／Anthropic／OpenAI，更新说明与公开来源链接；选择可在应用重启后保留。
- 设置窗口打开时进入常规应用模式，关闭后恢复菜单栏模式，后台进程继续运行。
- 三种策略各处理简单询问、工程实施、已经明确三类合成样例，共 9 组真实 Codex 调用最终成功。工程样例读取了测试工程中的实际实现，三个明确指令样例原样保留，测试工程内容保持不变。
- App 内手动输入模式到 Codex 返回结果的调用链路，运行收据记录所选策略。测试期间出现过 429 限流，部分请求经过间隔重试。

## 使用限制

- 上述验证不代表所有应用都能自动回填。快捷键／右键、真实输入框回填、等待期间的输入变更与撤销，需要在目标应用中单独验证；当前版本没有完成全面的跨应用兼容性验证。
- Conductor／Codex 的本地存储结构可能变化。匹配不唯一或存储结构不兼容时，本工具不会猜测原会话。
- 当前构建脚本使用临时签名。更新可执行文件后，macOS 可能要求移除旧权限条目并重新添加应用。下载包尚未经过 Apple 公证。
- Codex 服务可出现限流、网络或登录错误。界面中的生成状态与完整链路验证应分别判断。

## 自行验证

运行自动检查和打包：

```sh
swift test
zsh Scripts/build-app.sh
```

可用 `--smoke-check` 测试真实 Codex 调用；它会使用本机登录并消耗账户用量。请仅将可发送给所选模型的文字、截图或工程素材用于此检查。

原始运行记录、截图、会话材料和本机诊断笔记不包含在公开仓库中。
